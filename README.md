# Predicción de Cancelación de Clientes (IBM Telco Customer Churn)
**Modelos y Simulación de Sistemas I - Universidad de Antioquia**

**Integrantes:** Heidy Dayana Gamboa Chaverra, Santiago Restrepo Rodriguez, Norbey David Rincón Bedoya.

Este repositorio contiene el proyecto integrador por fases. Cada fase tiene su propia carpeta y su propio README:

| Carpeta | Contenido | Cómo empezar |
| :--- | :--- | :--- |
| [`fase-1/`](fase-1/README.md) | Notebook de EDA, preparación, modelo base y Regresión Logística. | `cd fase-1` y abrir `notebook.ipynb` |
| [`fase-2/`](fase-2/README.md) | Aplicación reproducible: `train.py`, `predict.py`, versionamiento, Docker y pytest. | `cd fase-2` y seguir su README |

Los archivos **no están en la raíz**: entre a la carpeta de la fase antes de ejecutar nada.

> Datos: muestra de IBM de una empresa ficticia (uso didáctico).
